# Women Safety Evidence Portal (SafeHer)

A confidential web portal designed to help sexual assault survivors collect forensic evidence, find nearby hospitals, and file anonymous police reports without revealing their identity.

## Features
- **Confidential & Anonymous**: No personal data stored, no login required.
- **Hospital Finder**: Uses geolocation to find the nearest hospital for forensic evidence collection.
- **Anonymous Reporting**: File a case and receive a unique Case ID for tracking.
- **Direct Police Submission**: Reports are encrypted and sent directly to the relevant police station.
- **Design**: Dark-themed, privacy-first interface with a "Quick Exit" button.

## How to Run
Simply open `index.html` in any modern web browser. No server setup required.

## Technologies Used
- HTML5
- CSS3 (Vanilla CSS, custom variables)
- JavaScript (ES6+)
- Leaflet.js (for maps)
